Installation rapide

1. Copier le dossier `marketing-site-studio-generator` dans `wp-content/plugins/`.
2. Activer le plugin dans Extensions.
3. Ouvrir le menu “Generateur prospects”.
4. Renseigner l’URL de l’application et le mot de passe, puis enregistrer.
5. Coller l’URL d’un prospect et generer une page brouillon.
